# Варианты СБК Инструменты для Windows

## Что выбрать

`ScanDocument.exe` — переносная однофайловая версия. Её можно хранить в любой папке или на внешнем носителе. При каждом запуске она распаковывает программные компоненты в уникальную папку `%TEMP%`, а после закрытия очищает её. Формат, имя и упаковщик версии 2.8.3 сохранены без изменений.

`SBK-Tools-Fast-Setup-2.8.3-x64.exe` — установщик версии «СБК Инструменты — быстрый запуск». Установка выполняется один раз для текущего пользователя, без прав администратора. В меню «Пуск» появляется ярлык «СБК Инструменты — быстрый запуск»; создание ярлыка на рабочем столе можно отключить в установщике. Последующие запуски открывают `SBK-Tools-Fast.exe` непосредственно из каталога установки и не распаковывают полный runtime в `%TEMP%`.

Это два независимых продукта:

- portable: имя `СБК Инструменты`, идентификатор `ru.sbk.tools`, итоговый файл `ScanDocument.exe`;
- installed: имя `СБК Инструменты — быстрый запуск`, идентификатор `ru.sbk.tools.fast`, приложение `SBK-Tools-Fast.exe`;
- установка fast-версии не заменяет и не удаляет `ScanDocument.exe`;
- обновление fast-версии относится только к fast-версии и требует явного запуска её установщика пользователем.

## Где находятся компоненты и данные

NSIS по умолчанию размещает fast-версию в пользовательском каталоге внутри `%LOCALAPPDATA%`. В каталоге установки находятся только программа и неизменяемые компоненты релиза: Tauri-приложение, scanner worker, русский и английский OCR, LibreOffice, фиксированный WebView2, лицензионные файлы и манифест контрольных сумм runtime.

Пользовательские данные не хранятся в каталоге установки. По умолчанию используется существующая папка `%LOCALAPPDATA%\SBKTools\ProductData`; явно выбранное расположение записывается в существующий указатель `SBKTools/workspace.txt`. Обе версии используют этот же выбор и ту же эксклюзивную блокировку редактора. Временные файлы одной операции сканера находятся в отдельном `runtime-cache` выбранной рабочей папки и удаляются владельцем процесса.

Установщик и деинсталлятор не перемещают, не переименовывают и не удаляют `ProductData`, пользовательские документы или резервные копии. После удаления fast-версии portable-версия продолжает открывать ту же рабочую папку.

## Сборка

Перед упаковкой должны быть подготовлены sidecar, `runtime-resources`, модели OCR, LibreOffice, фиксированный WebView2 и `resource-manifest.json`.

```powershell
python scripts/generate_runtime_manifest.py --root src-tauri/runtime-resources --worker src-tauri/binaries/sbk-scanner-worker-x86_64-pc-windows-msvc.exe
./scripts/package_windows_installed.ps1 -Target x86_64-pc-windows-msvc -Version 2.8.3
```

Скрипт проверяет наличие офлайн-компонентов и лицензий, проверяет trusted runtime manifest, собирает приложение с отдельной Tauri-конфигурацией, закрепляет `asInvoker`, создаёт NSIS и публикует файл `release-artifacts/SBK-Tools-Fast-Setup-2.8.3-x64.exe` с SHA-256. Полный runtime превышает внутренний предел NSIS в 2 ГБ, поэтому он заранее упаковывается в один проверяемый `tar.zst`; маленький отдельный `windows-installer-helper` разворачивает его непосредственно в каталог установки. Архив используется только при установке: ежедневный запуск открывает `SBK-Tools-Fast.exe` напрямую и ничего не распаковывает в `%TEMP%`. `scripts/package_windows_portable.ps1` вызывается отдельно и продолжает создавать только `release-artifacts/ScanDocument.exe`.

## Обновление и удаление

Для обновления fast-версии пользователь скачивает и явно запускает новый `SBK-Tools-Fast-Setup-<версия>-x64.exe`. Установщик с отдельным идентификатором не затрагивает portable-вариант. Более старая fast-версия не устанавливается поверх новой.

Удаление выполняется через «Параметры → Приложения» Windows или штатный `uninstall.exe` в каталоге fast-версии. Удаляются приложение и его ярлыки. `ProductData` остаётся на месте; при необходимости пользователь удаляет или переносит его самостоятельно после резервного копирования.

## Быстрая проверка релиза

Отдельная CI-задача `Windows x64 installed fast start` выполняет следующие проверки на чистом Windows-агенте:

1. устанавливает NSIS для текущего пользователя и проверяет отдельные имя, исполняемый файл и ярлык;
2. проверяет `asInvoker`, лицензии, WebView2, OCR, LibreOffice, scanner worker и runtime manifest;
3. дважды запускает установленное приложение и подтверждает появление окна без полного каталога распаковки в `%TEMP%`;
4. проверяет, что повторный запуск не изменяет базы с текущей схемой;
5. одновременно запускает portable и installed, подтверждая сохранение одного владельца блокировки редактора;
6. удаляет fast-версию и подтверждает сохранность контрольного файла внутри `ProductData`.

Windows 10 и Windows 11 используют одинаковый x64-пакет. До публичного выпуска остаётся обязательной ручная проверка ярлыков, системного диалога удаления, антивирусной репутации и первого запуска на обеих чистых версиях Windows.
