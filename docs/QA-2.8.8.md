# Проверка 2.8.8

## Проверено до упаковки, 15 сентября 2026

- Frontend: 402 автоматических теста, TypeScript и production build.
- Python worker: 121 тест; Ruff. Rust: 84 теста и clippy. Один прежний
  тест освобождения workspace-блокировки дал нестабильное падение при первом
  параллельном прогоне; отдельный и повторный полный прогоны успешны.
- Встроенный Windows installer-helper: отдельные тесты и проверки контракта
  установщика; реальная установка проверяется в Windows CI.
- Экспертный калькулятор в реальном локальном интерфейсе: 800×600, 1024×720,
  1280×720. Раскрыты агент, соисполнители, валюта, финансирование, этапы оплаты,
  конкуренты. Заполнен синтетический расчёт, проверены ошибки долей платежей,
  итоговая цена и сравнительный график. Общая рабочая область не переполняется;
  широкая таблица расходов прокручивается внутри своей карточки.
- Нативное приложение macOS с текущим Python worker: восьмистраничный PDF,
  четырёхстраничный DOCX, подготовка соседей, переходы по готовым страницам,
  смена пресета. Возврат из кадров сохраняет открытый файл и два эффекта.
- Голубой маркер нанесён мышью и изменён на розовый; белый штрих нанесён мышью.
  Оба переведены в 100% непрозрачность. Итоговый восьмистраничный PDF сохранён,
  третья страница отрисована Poppler и просмотрена: цвета сохранены, линии под
  непрозрачными областями закрыты.
- Изолированный исходный PDF заменён другим тестовым PDF по тому же пути.
  Переход к закэшированной странице отклонён, выводится сообщение об изменении
  исходника, сохранение с прежней разметкой блокируется. Автоматические проверки
  дополнительно контролируют смену исходника перед и во время сохранения.
- Для сохранения по блокам версия исходника фиксируется до выбора выходной
  папки и сохраняется на всю операцию. Замена/сброс документа во время обработки
  заблокированы; смена исходника во время выбора пути отменяет старое сохранение.
  В нативном интерфейсе сохранены два блока по четыре страницы (1–4 и 5–8),
  проверены их фактические размеры и количество страниц. На время обработки
  кнопка замены файла действительно недоступна; после завершения снова активна.
- Иконка проверена в размерах 512 и 32 px. Форматы ICO/ICNS и ссылки установщика
  проверяются тестами. Видимое имя Windows изменено без смены идентификатора,
  имени исполняемого файла и пути обновления.

## Проверки окончательной поставки

Release workflow запускает проверку `preparePreview` на собранном sidecar и
внутри готового Mac-приложения / установленной Windows-копии. Проверяются PDF и
DOCX, три подготовленные страницы, PNG, контроль версии исходника, повторное
чтение после удаления временных копий и запрет сохранения изменённого источника.
Отчёты JSON и журналы сохраняются в артефактах этого workflow. Затем повторно
проверяется целостность встроенного runtime.

Успешный локальный Python-прогон не считается проверкой готового бинарного
компонента. Результат упаковки подтверждается соответствующим Release workflow.

## Ограничения

- Тестирование использовало только синтетические файлы и временную базу.
  Пользовательские базы и схемы не изменялись.
- Нет проверки на конкретной сетевой папке пользователя и двух физических
  Windows-компьютерах. Windows GUI вручную не проверен; CI проверяет реальную
  установку/обновление и встроенный обработчик документов.
- Ускорение зависит от документа и диска. Фоновая подготовка ограничивается
  ближайшими страницами; весь большой документ не растеризуется при открытии.
- Отдельные подписи Developer ID/нотаризация Apple и Authenticode Windows не
  настроены; системные предупреждения не отключаются.
