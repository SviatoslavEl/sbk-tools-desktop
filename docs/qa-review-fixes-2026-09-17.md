# Исправления по критическому обзору — 17 сентября 2026

Рабочая ветка: `codex/v2.8.9-reliability-ux`, база — `2716d93` (2.8.8).
Это отчёт об исходниках и локальных проверках, не подтверждение опубликованного релиза.
Версия поставки и GitHub Release этим этапом не менялись.

## Что изменено

| Область обзора | Исправление |
| --- | --- |
| Пакеты и блоки PDF | План имён до запуска, нумерация конфликтов, атомарный запрет перезаписи, результаты отдельно по файлам, повтор только незавершённых файлов. |
| Просмотр реестров | Полные читаемые карточки договоров, сотрудников и компаний; вложения и история доступны без права изменения. |
| Сохранение и архивирование | Ожидание результата, защита повторного нажатия и закрытия, сохранение формы при ошибке и возможность повтора. |
| Готовность кадров | «Полнота карточки» вместо обещания готовности к закупке; наличие файлов отдельно, «Документы не добавлены» при их отсутствии. |
| Главная | Очередь просроченных, сегодняшних и ближайших задач; переход к конкретной записи; поданные закупки не получают просрочку подачи. |
| Работа в сканере | Единые предупреждения о замене несохранённых правок; ограниченная история отмены/повтора; добровольный локальный черновик настроек. |
| Достоверность сканера | Отдельный итоговый просмотр тем же обработчиком, что создаёт PDF; повтор соответствует неудавшемуся действию. |
| Калькулятор | Разделены черновик и запись в базе; исправлены гонки чтения/сохранения; расчёт остаётся при смене инструмента, включая просмотр; краткий результат до итогового шага. |
| Закупки | Семь этапов вместо вложенных наборов вкладок; все 18 прежних разделов сохранены; дата/ревизия и явное сравнение снимков с реестром. |
| Плотность реестров | Краткий/подробный вид, выбор столбцов, локальное сохранение предпочтений, сворачиваемые фильтры и переходы по разделам договора. |
| Контрагенты | Выбор чекбоксами и точный состав массового действия; архивные компании исключены из новых связей, старые связи сохранены. |
| Выгрузка и копии | Меню выбранных документов/таблиц отделено от полного переноса; резервные копии не называются архивом записей. |
| Состояния загрузки | Разделены загрузка, пустой список, отсутствие совпадений и ошибка; добавлен повтор. |
| Настройки | Четыре раздела: рабочая папка, резервные копии, интерфейс, обслуживание. Технические детали сворачиваются; факт проверки копии отмечен только для текущего сеанса. |

Схемы и имена баз не изменялись. Рабочие пользовательские данные не переносились,
не редактировались и не удалялись. Авторизация, пароли и полномочия владельца не
менялись. Изменения общие для macOS и Windows; переносимая Windows-сборка не добавлялась.

## Видимая проверка интерфейса

Использованы текущие исходники, нативная debug-сборка macOS с актуальным Python
worker и отдельная база `/tmp/sbk-qa289.jH4n2S/CleanProductData`. Браузерная
проверка использовала только локальный режим предпросмотра и синтетические записи.

- Сканер: открыл `simple.pdf`, нанесён голубой маркер мышью, изменена
  непрозрачность, выполнены отмена и повтор. Итоговый просмотр открыт и визуально
  проверен. Реально сохранён `qa289-marker.pdf`, файл повторно отрисован Poppler:
  положение, цвет и прозрачность соответствуют предпросмотру; страница читаема.
- Кадры: введена тестовая карточка. Некорректная почта отклонена без сброса формы;
  незаполненное назначение показано в разделе «Работа». После заполнения юрлица,
  отдела и должности карточка сохранена. В режиме просмотра открыты полные данные;
  изменения недоступны. Нажатие свободной области слева закрывает карточку.
- Калькулятор: в режиме просмотра изменены название и себестоимость, итог
  пересчитан. Сохранение в базу недоступно. После перехода в кадры и обратно
  значения сохранились. Проверен отдельный статус черновика и записи в базе.
- Настройки: проверены группировка, читаемость и активный пункт; создана и проверена
  копия только тестовой базы. Состояние «не проверялась» сменилось на фактическую
  дату проверки текущего сеанса. Производственные копии не затрагивались.
- Окно 1024×720: проверены экспертный калькулятор и все семь этапов закупки.
  Общая страница не имеет горизонтального переполнения; широкая таблица расходов
  остаётся внутри собственного прокручиваемого контейнера.
- Закупки: создана и сохранена синтетическая карточка, дата выбрана через календарь.
  Просроченный срок появился на главной, ссылка открыла нужную карточку.
  После статуса «Подана» просрочка подачи исчезла. Ошибок консоли не обнаружено.
- Контрагенты: создана тестовая компания, проверены чекбокс и предупреждение с
  точным именем/количеством. Действие архивирования отменено. Переключение раздела
  с отсутствующими компаниями показывает «Нет совпадений» и сброс фильтров.

Это целевой прогон исправленных сценариев, а не заявление о ручной проверке
каждой кнопки и каждой возможной комбинации данных.

## Дополнение: компактные блоки редакторов

По отдельному запросу добавлены раскрывающиеся строки для документов сотрудника
(дипломов, сертификатов, допусков и договоров), назначений, документов договора,
контактов, подписантов и связей компаний. Существующие заполненные записи
свёрнуты; новая пустая запись раскрыта. Название и краткие сведения видны в строке.
Кнопка «Свернуть блок» скрывает поля, не удаляя их и не сохраняя карточку в базу.
Набор текста не вызывает самопроизвольного сворачивания. Ошибка обязательного
поля раскрывает соответствующий блок сотрудника (при ошибке компании — её блоки).
Состояние раскрытия не добавляется в базу.

В видимом браузерном предпросмотре проверены два синтетических сертификата:
ввод названия, номера и издателя, независимое сворачивание, раскрытие клавиатурой,
сохранение и повторное открытие карточки. Значения сохранились; оба документа
показаны компактными строками. Незавершённое назначение автоматически раскрылось
при попытке сохранения. Для тестовой компании заполнен, свёрнут и сохранён
контакт; имя, должность и почта появились в реестре. Пользовательские данные
не использовались — только локальные записи QA в режиме предпросмотра.

## Автоматическая проверка

- Frontend: 490 тестов в 77 файлах — полный Vitest-прогон, включая реальные
  обработчики форм и моделирование отложенных/неудачных операций; TypeScript и
  production-сборка Vite прошли успешно.
- Worker: 131 тест, включая совпадающие имена, конкурирующие публикации,
  повреждённые ссылки и побайтовое сравнение JPEG итогового просмотра с JPEG из PDF.
- Rust: 85 тестов; проверка форматирования; сборка debug и проверка конфигурации
  `installed-fast-start`. Дополнительно проверяется планирование имён файлов.
- Проверка изменения базы выполнялась только на временных данных. Весь файл
  `src-tauri/src/database.rs` и существующие схемы сохранены без изменения.

## Ограничения и остаточные проверки перед выпуском

- Готовые установщики Windows и пакет macOS с новым worker в этом этапе не
  выпускались; GitHub Actions и публикация не запускались. Нужен отдельный прогон
  упаковки и smoke-тест готовых компонентов перед выпуском.
- Реальная пользовательская SMB-папка и два физических Windows-компьютера не
  проверялись. На POSIX-хранилище без атомарной публикации через hard link пакет
  безопасно откажет и предложит локальную папку; чужой файл не заменяется.
- Локальный черновик сканера добровольный, действует в текущем окне до 24 часов,
  не переживает закрытие приложения. Хранятся только настройки и пути, без PDF,
  содержимого изображений и OCR; объём ограничен.
- Итоговый просмотр не проверяет OCR-слой и метаданные. При разделении на блоки
  показано качество первого блока, содержащего страницу; это отмечено в интерфейсе.
- Во встроенном браузере одно нативное предупреждение о замене черновика прервало
  автоматическое управление вкладкой. Проверка продолжена в отдельной вкладке и
  нативном приложении; логика отказа/подтверждения дополнительно покрыта тестами.
- Vite предупреждает о размере общего JS-файла более 500 КБ. Сборка проходит;
  разделение загрузки модулей остаётся отдельной оптимизацией, не скрытой ошибкой.
