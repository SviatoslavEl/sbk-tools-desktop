Дата сверки: 18 сентября 2026. База сравнения — аудит
`docs/audit-2.8.9-2026-09-18.md` для коммита `c5841e8`.

Это отчёт о рабочих изменениях, а не объявление выпущенного релиза. На момент
составления в `package.json` ещё указана 2.8.9; название документа обозначает
планируемую функциональную итерацию. Публикация релиза, push и выдача готовых
Windows/macOS-пакетов этим документом не подтверждаются.

## КП: существенные решения реализации

- Новая аддитивная база `commercial-proposals`; старые семь модулей не
  переименовываются и не удаляются. Reader старой папки без новой базы получает
  пустой список, не создаёт её. Восстановление старой семимодульной копии не
  удаляет уже существующие новые данные КП.
- Деньги считаются десятичной целочисленной арифметикой: количество до шести
  знаков, цена до четырёх, скидка до двух; округление half-up по строке,
  суммы в копейках. «Без НДС» и «НДС 0%» различаются. Нулевая итоговая цена
  требует отдельного согласия, которое сбрасывается при редактировании.
- Из калькулятора переносится вычисленная цена, а не старое поле введённой цены.
  Убыточный расчёт требует подтверждения. Из закупки источник выбирается явно;
  смена убыточного источника сбрасывает согласие. НМЦ не подставляется автоматически.
- Экспорт строится из закрытого публичного DTO. Себестоимость, маржа, внутренние
  заметки, исходные снимки/ID и история не передаются в клиентский документ.
  Пути вложений идут отдельным служебным списком; backend проверяет их границы
  и хеши. Шаблон не сохраняет стороны, цены, подпись и внутренние заметки.
- Готовая/отправленная редакция не редактируется напрямую. Новая редакция получает
  новый record ID с тем же family ID; копия — новую семью. Возврат из истории
  сохраняет новую редакцию, не затирая текущую.
- Черновик сохраняется последовательно; сбой автосохранения не запрещает ручной
  повтор сохранения. Ошибка чтения черновика не превращается в разрешение записи
  поверх него. Старое незавершённое КП перед handoff требует выбора
  «Сохранить / Заменить / Отмена».
- Для каждой новой карточки, копии и редакции выделяется собственный стабильный
  write ID, отдельный от family ID. Его используют staging вложений, оболочка
  черновика и первое сохранение. После записи UI принимает `saved.payload` с
  окончательными путями. Логотип шаблона копируется в собственную staging-сессию
  шаблона, не отбирая файл у незавершённого КП. Копирование несохранённого КП
  также переносит временные вложения в отдельную сессию.
- Viewer экспортирует сохранённое КП и может сделать явно локальную копию.
  Она не сохраняет черновики, карточки, новые файлы или шаблоны в общей папке.
  Потеря редакторского доступа повторно проверяется перед записью.
- Preview показывает PNG, полученные из настоящего сгенерированного PDF,
  по одной странице; устаревший ответ/отмена не устанавливают старое изображение.
  Временный preview очищается отдельной ограниченной командой. «Открыть PDF»
  передаёт `reveal:false`, то есть открывает файл, а не папку.
- HTML не выдаётся под расширением DOCX/PDF. Занятое имя не перезаписывается:
  пользователь получает ошибку и может повторно выбрать другой путь.
  Автоматический подбор свободного суффикса в текущем UI не реализован.

полный Windows/SMB/E2E-прогон. «Частично» отделяет устранённый дефект от расширенной
рекомендации, которая ещё не реализована.

## Сопоставление с рекомендациями развития

| Рекомендация аудита | Текущее состояние |
| --- | --- |
| Безопасный мастер импорта с diff | Безопасный merge и предварительные блокеры реализованы; поклеточный/подокументный diff отложен |
| Центр состояния | Реализован в описанном выше объёме, без обещания сетевой диагностики с двух ПК |
| Конструктор КП | Реализован; окончательная нативная визуальная приёмка перечислена отдельно ниже |
| Папка заявки одним пакетом | Индивидуальный выбор файлов кадров/договоров реализован. Единая папка заявки со снимками всех модулей и общей описью не добавлена |
| Проект сканера / целевой размер МБ | В текущем коде есть локальное добровольное восстановление настроек и проверка исходника; полноценная новая система проектов и пробное адаптивное сжатие под заданные МБ этим изменением не заявляются |
| Единый контроль сроков доверенностей/сертификатов на срок закупки | В КП есть предупреждения по доверенности; единый межмодульный контроль на весь срок подачи/работ отложен |
| Глобальный поиск с полным индексом файлов | Реализован поиск карточек и уже извлечённого текста; фоновая OCR-индексация всех файлов/страниц и постоянный дисковый индекс отложены |
| Командная очередь/общий журнал работы | Центр показывает локальные операции и текущую сессию. Полная командная очередь и общий журнал с автором/устройством/причиной не добавлены |
| Диспетчер миниатюр, виртуализация/групповое перемещение | Не реализованы этой итерацией |
| Обрабатывать только используемые страницы до OCR/растрирования | Не заявляется закрытым без отдельного измерения; текущие merge-регрессии проверяют корректность и исходник, а не этот выигрыш скорости |
| Пробная обработка разных страниц для оценки размера | Отложена |
| Нагрузочный прогон реестров 1000+ и виртуализация | Не выполнен; подтверждённого результата/ускорения на таком объёме нет |
| Автоотправка заявок, автономные изменения ИИ, несколько одновременных writers, большой новый редизайн | Намеренно не добавлены, как рекомендовано аудитом. Сетевая папка остаётся источником данных, сервер не требуется |

## Критерии исходного аудита перед будущим выпуском

| Критерий | Фактическое состояние |
| --- | --- |
| 1. Отказы восстановления/rollback не уничтожают оригиналы | Есть production failure-injection тесты, сохранён recovery stage; реальная авария SMB не проверена |
| 2. Проверенная копия восстанавливается; повреждённые pins защищены | Есть temp roundtrip и fail-closed pins; объёмные граничные файлы проверены контрактом, не реальным 2 GiB архивом |

| 4. Полный маршрут готового desktop, ошибки/клавиатура/масштаб/доступность | Компонентные тесты и ограниченный видимый прогон есть; полный маршрут на обеих ОС **не завершён** |
| 5. Проверка именно упакованного worker | Свежий macOS arm64 onefile: 6/6 protocol smoke + native PDF-preview/ZIP; финальные Windows и подписанный macOS пакет ещё не проверены |
| 6. Установка и обновление с сохранением базы | **Не выполнено** для будущего пакета |
| 7. Согласованность версий и read-only совместимость | Новая база аддитивна и старый restore покрыт; финальные версии пакетов ещё не зафиксированы. Поле версии клиента в editor-сессии/updater не добавлялись |

проверки, называть локальные тесты полноценной SMB-приёмкой или публиковать релиз
