# Безопасная миграция и происхождение модулей

## Исходные проекты

- ScanDocument: отдельный Python/PySide6-проект. Исходный проект не изменяется; в этот репозиторий перенесено только headless-ядро обработки документов.
- Bid Buddy: отдельный React/TypeScript-проект с незакоммиченными изменениями. Он не изменяется и остаётся контрольным источником расчётных сценариев.

Копирование выполнено в новый репозиторий. Удаление, reset или очистка исходных рабочих деревьев не применялись.

## Реализованная схема

1. Общая оболочка Tauri/React создана отдельно от исходных приложений.
2. Расчётное ядро покрыто тестами НДС, целевой маржи, расходов от цены контракта, убытка и рекомендации по конкурентам.
3. ScanDocument выделен в автономный Python worker с версионированным JSON-lines протоколом.
4. Проверены PDF, DOCX через вложенный LibreOffice, OCR через Tesseract, факсимиле и отмена процесса.
5. Каждый инструмент получил отдельную SQLite-базу и историю изменений.
6. Импорт договоров проходит сопоставление колонок и предпросмотр до записи.
7. Перед миграцией схемы и восстановлением создаётся страховочная резервная копия.
8. Выполняются независимые сборки Windows x64, macOS arm64 и macOS x86_64; ручной workflow не публикует релиз.
9. Однофайловый Windows-launcher работает с уровнем `asInvoker`, очищает аварийные временные каталоги и включает закреплённый WebView2 Fixed Runtime.
10. Восстановление выполняется транзакционно после проверки манифеста и SHA-256; доступны зашифрованные копии и dry-run аудит вложений.

## Правила будущих обновлений

- Не менять смысл существующих формул без отдельного теста и заметки в релизе.
- Повышать `SCHEMA_VERSION` только вместе с миграцией и тестом восстановления.
- Не открывать SQLite из Python worker: владельцем баз остаётся Rust-host.
- Не перезаписывать исходные документы; результат всегда сохранять новым файлом.
- Обновлять LibreOffice/Tesseract только с закреплением версии, контрольной суммы и лицензионных notices.
- Перед выпуском проверять сохранение/восстановление, DOCX, OCR, факсимиле, CSV/XLSX и запуск пакета на чистой системе.
