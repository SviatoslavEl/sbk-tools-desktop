# План безопасной миграции

1. Зафиксировать воспроизводимые снимки ScanDocument и незакоммиченного Bid Buddy.
2. Создать regression/golden baseline обоих приложений.
3. Стабилизировать общую Tauri/React-оболочку и portable workspace.
4. Перенести расчётное ядро Bid Buddy без изменения формул.
5. Добавить дополнительные расходы и графики с golden-тестами.
6. Выделить headless worker из ScanDocument и сохранить существующий PySide UI до паритета.
7. Встроить PDF, затем DOCX, OCR, отмену и факсимиле.
8. Реализовать реестр договорного опыта: ручной ввод, импорт и экспорт.
9. Реализовать кадровый реестр: основания, документы, сроки, импорт и экспорт.
10. Выполнить packaging, clean-system QA, SBOM и лицензионный аудит.

Каждый этап заканчивается собираемой версией. Старые реализации удаляются только после доказанного функционального паритета.
