# СБК Инструменты 2.8.4

Обновление для Windows x64 и macOS Apple Silicon.

- Установщик Windows заранее проверяет доступность выбранной папки для записи и объясняет, как выбрать каталог без прав администратора.
- В общей базе отображается текущий редактор. Статус обновляется без перезапуска; обычный пароль не позволяет забрать занятые права.
- В кадрах появились чекбоксы: экспортируются только выбранные записи, групповое архивирование требует подтверждения.
- Издатель — СБК, автор — Elbakide S.E. Дополнены сведения в лицензии и окне «О программе».
- В сканере добавлена обработка перетаскивания PDF/DOCX в окно. Несколько документов можно отправить на объединение или пакетную обработку.
- Повторное применение фильтров использует ограниченный кеш исходных растров страниц, без изменения оригиналов.
- Для факсимиле добавлены варианты примерки 40 мм (печать) и 60 мм (подпись). Пропорции сохраняются, текущий размер отображается в миллиметрах. Эти размеры — ориентиры, а не обязательный стандарт; белые поля изображения входят в измерение.

Состав: переносной Windows EXE, отдельный установщик Windows с быстрым запуском и архив приложения macOS. Установщик и переносная версия остаются независимыми вариантами.

Структура существующих баз не изменяется. Административная панель, принудительная передача прав и административная очистка баз в эту версию не входят.
