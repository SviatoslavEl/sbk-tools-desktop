# СБК Инструменты 2.8.6 — исправленный установщик Windows r2

Это исправление установщика, а не новая версия приложения. Приложение,
сканер и встроенные компоненты остаются версии 2.8.6. Пакет macOS не меняется.
Исходный релиз `v2.8.6`, его тег и файлы не заменяются.

## Что изменилось

- Обновление больше не переименовывает всю папку установленной программы.
  Это устраняет отказ, когда Windows удерживает сам каталог или запущенный
  установщик находится внутри него.
- Заменяются только известные компоненты программы. Папка `ProductData`
  и посторонние пользовательские файлы остаются на месте.
- Занятые компоненты проверяются до распаковки. При ошибке показываются
  конкретный путь и код Windows, а имя удерживающего процесса — если его
  удалось определить. Чужие процессы автоматически не завершаются.
- После освобождения файла можно повторить операцию. Журнал сохраняет этапы
  установки, а не только последнюю строку ошибки.
- Параллельные обновления одной папки исключены. При ошибке замены выполняется
  откат; если откат завершился не полностью, резервные файлы сохраняются,
  а следующая установка блокируется с указанием места восстановления.

## Состав и проверка происхождения

Файл для Windows: `SBK-Tools-Fast-Setup-2.8.6-r2-x64.exe`.
В свойствах установщика указана редакция `2.8.6.2`, в приложении — `2.8.6`.

Сборка проверяет SHA-256 исходного официального установщика, извлекает
его сжатый пакет программы без запуска и повторно проверяет совпадение
пакета после включения в новый установщик. Рядом с EXE публикуются
контрольная сумма и `provenance.json` с исходным файлом, хешами и коммитом.

Перед публикацией обязательны проверки настоящего установщика на Windows:
установка, обновление, блокировки каталога и отдельных файлов, запуск
установщика из папки программы, сохранность тестовых данных, удаление и
повторная установка. Отдельный прогон установленного приложения проверяет
запуск, сканер и совместную работу редактора и режима просмотра.

Проверки выполняются на изолированном стенде с синтетическими данными.
Они не подтверждают конкретную причину блокировки на компьютере пользователя
без полного пути и нового диагностического журнала.
