# СБК Инструменты 3.0.1

Релиз ветки 3.0 объединяет работу с ИИ, подготовку коммерческих предложений,
глобальный поиск и контроль состояния приложения. Версия 3.0.1 также исправляет
упаковку встроенного LibreOffice на Mac.

Состав: установщик Windows x64 и архив приложения macOS для Apple Silicon.
Portable-версия Windows не выпускается.

## ИИ и извлечение данных

- Единое окно для работы с PDF, DOCX, XLSX и текстом. Предусмотрены подключения
  Ollama и OpenAI-совместимых сервисов, локально, в сети организации или через
  внешний сервис. Модель ИИ в дистрибутив не включена.
- Результаты можно проверить и передать в закупки, договоры, кадры, контрагентов
  и конструктор КП. Передача открывает подготовленный черновик, а не сохраняет
  сведения в общую базу без участия пользователя.
- Улучшено извлечение дат, номеров документов, артикулов, табличных позиций и
  условий. Для результатов показываются источники и подтверждающие цитаты;
  противоречивые и неподтверждённые сведения выделяются для проверки.
- Сведения о сертификатах из поддерживаемых таблиц автоматически включаются в
  подготовленный результат с проверкой принадлежности сотруднику. Реквизиты не
  заменяют файл оригинала сертификата; дата экзамена не подменяет дату выдачи.
- Добавлены анализ по отдельным направлениям, прогресс подготовки и отмена.
  Неразобранный ответ остаётся доступен для просмотра и копирования.

## Коммерческие предложения и подбор документов

- Конструктор КП: позиции, расчёт стоимости, оформление, редакции, выгрузка
  DOCX/PDF и архив выбранных приложений. Внутренние заметки и себестоимость
  отделены от клиентского документа.
- Усилена защита черновиков КП при сохранении, повторном получении данных из
  другого инструмента и смене рабочей папки.
- В подборе кадров и опыта по договорам можно выбрать конкретные сертификаты
  и документы для включения в выгрузку.

## Сканер

- Оптимизированы кэш предпросмотра и повторное использование подготовленного
  DOCX при перелистывании и обработке.
- Предпросмотр адаптируется к доступной высоте окна. Уточнены масштабирование,
  отображение размера факсимиле и его геометрия на странице.
- Исправлены сценарии восстановления черновика и появления устаревших результатов
  после замены документа или перехода между инструментами.
- Для PDF без текста предусмотрен явный маршрут в сканер для OCR и возврат
  результата в текущую задачу ИИ. Повторная отправка модели выполняется пользователем.
- На Mac исправлено формирование состава LibreOffice до создания манифеста
  целостности. Строгая проверка ресурсов сохранена.

## Поиск, общая папка и интерфейс

- Глобальный поиск по карточкам с переходом в нужный раздел. Это не сплошной OCR
  содержимого всех вложений.
- Центр состояния показывает сведения о рабочей папке, редакторе, резервных
  копиях и операциях текущего сеанса.
- Сокращены повторные чтения реестров. В настройках доступны локальная пауза
  сетевых обращений и экспорт диагностического журнала для разбора задержек.
- Улучшены управление столбцами и читаемость таблиц договоров и кадров,
  компактность калькулятора, сообщения о загрузке и ошибках.
- Исправлена передача фокуса во вложенных окнах. Необязательные даты сертификатов
  явно отображаются как «Не указана», пока пользователь их не заполнит.

## Проверка и обновление

- Обе платформенные сборки и публикация завершены успешно. На Windows проверены
  установка, обновление, повторные запуски, блокировка общей базы, восстановление
  после сбоя и удаление с сохранением пользовательских данных.
- На Mac проверены запуск приложения, обработка документов, строгая подпись и
  целостность 22 846 ресурсов. Скачанные из релиза файлы сверены по SHA-256;
  Mac-архив дополнительно распакован и повторно проверен.
- Сервер не требуется: сохраняется работа с общей сетевой папкой. Перед обновлением
  сделайте резервную копию и закройте программу на рабочих местах. Скорость доступа
  зависит от вашей сети и хранилища; проверки сборки не заменяют приёмку на вашей SMB-папке.
- Результаты ИИ требуют проверки по оригиналам, особенно при неполном извлечении
  или OCR. Автоматическое дополнение не гарантирует полноту и правильность документа.
- macOS: подпись ad-hoc, без Apple Developer ID и нотариальной проверки Apple.
  Windows: установщик без Authenticode-подписи. При первом запуске возможны
  предупреждения операционной системы.
