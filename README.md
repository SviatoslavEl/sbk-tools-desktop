# СБК Инструменты 2.8.3

Открытое локальное desktop-приложение для Windows и macOS:

- тендерный калькулятор с дополнительными расходами, конкурентами, рекомендацией цены и графиками;
- обработка PDF/DOCX с пресетами, OCR и размещением факсимиле;
- реестр опыта по договорам со статусами стадии, оплаты и актов;
- кадровый реестр с основанием сотрудничества и документами сотрудников;
- рабочее место закупки с матрицей соответствия, опытом, командой, партнёрами и документами заявки;
- полный офлайн-контур закупки: версии документов, доказательства, Go/No-Go, договорные правила, денежный поток, загрузка, комплект и результат план/факт;
- календарь тендеров с распределением заявок, внутренними сроками, оценкой сложности, квалификационным подбором и графиком загрузки команды;
- обзор сроков, рисков и последних изменений без изменения исходных записей.

Данные модулей разделены. Рабочее место закупки только предлагает подходящий опыт и сотрудников, разрешённых для раскрытия; окончательный выбор всегда делает пользователь. Все операции, OCR и конвертация DOCX выполняются на компьютере без серверной обработки и загрузок при первом запуске.

Версия 2.5 рассчитана на большие документы до 1 ГБ и 5000 страниц: предпросмотр открывает только выбранную страницу, итоговый PDF собирается потоково, а память не растёт вместе с объёмом JPEG-данных. Добавлены бережное и сильное сжатие с предварительной оценкой размера, маркер, штрих, обычное и печатное размытие, диапазон итоговых страниц, а также размещение факсимиле в заданной области или в воспроизводимой случайной позиции внутри неё.

Для совместной работы можно выбрать общую сетевую папку. Только один экземпляр с правом записи и эксклюзивной блокировкой становится редактором; остальные работают в режиме просмотра и экспорта. Доступны автоматическое обновление, проверяемые резервные копии и их ротация. Справочник собственных компаний и контрагентов пополняется из договоров, поддерживает отдельные карточки, ИНН и проверенные связи головных и дочерних организаций.

Контур будущего локального AI-сервера остаётся выключенным до утверждения API. AI не требуется для карточки закупки, расчётов, поиска, проверки правил, сохранения или экспорта и никогда не получает права напрямую менять подтверждённые данные.

## Готовые сборки

Сборки публикуются в разделе **Releases**:

- Windows 10/11 x64 — прежний переносимый `ScanDocument.exe`;
- Windows 10/11 x64 — отдельный установщик `SBK-Tools-Fast-Setup-2.8.3-x64.exe` для быстрого ежедневного запуска;
- macOS Apple Silicon — один `.app` (в ZIP). Сборка для Intel не выпускается.

Windows EXE является самораспаковывающимся solid-архивом Zstandard: он распаковывает только встроенные программные компоненты в уникальную временную папку, запускается с правами текущего пользователя и удаляет их после закрытия. Пользовательские записи находятся в системной папке данных `SBKTools/ProductData`, поэтому рядом с EXE не появляются обязательные файлы. Следующий запуск удаляет временные компоненты, оставшиеся после аварийного завершения.

Установочная версия — отдельный продукт «СБК Инструменты — быстрый запуск» с идентификатором `ru.sbk.tools.fast` и программным файлом `SBK-Tools-Fast.exe`. Она устанавливает Tauri, scanner worker, OCR, LibreOffice и фиксированный WebView2 в `%LOCALAPPDATA%` один раз и при последующих стартах не распаковывает весь комплект в `%TEMP%`. Обе версии открывают существующий `ProductData` и используют одну блокировку редактора. Удаление установленной версии не удаляет базы, документы и резервные копии.

Ручной запуск workflow создаёт неподписанный `.app` только для внутренней проверки: Gatekeeper может потребовать подтверждение пользователя. Публичный релиз macOS по тегу требует Developer ID, подпись и нотарификацию. Windows-сборка всегда запускается с обычными правами пользователя; при настроенном сертификате она подписывается Authenticode, а без сертификата публикуется как неподписанная сборка с SHA-256 для внутренней приёмки.

## Демонстрационные данные

В папке [`demo-data`](demo-data) находятся вымышленные DOCX, image-only PDF, JPEG и XLSX для проверки загрузки документов, OCR, фильтров, разрывов страниц и тендерной аналитики. Интернет и персональные данные для демонстрации не требуются.

## Разработка

Требуются Node.js 22+, Rust stable и Python 3.11/3.12.

```bash
npm ci
npm run check
npm run tauri dev
```

Worker сканера собирается отдельно:

```bash
python -m venv .venv-scanner
.venv-scanner/bin/pip install -e scanner-worker nuitka ordered-set zstandard
.venv-scanner/bin/python scripts/build_scanner_worker.py
```

LibreOffice и Tesseract входят в релизные пакеты. Скрипт `scripts/stage_libreoffice.py` загружает строго закреплённую версию LibreOffice и проверяет SHA-256.

## Portable workspace

По умолчанию приложение использует системную папку данных. Расположение можно изменить в настройках; перенос выполняется только после резервной копии.

```text
ProductData/
  settings/              отдельная SQLite-база
  calculator/            отдельная SQLite-база
  scanner/               отдельная SQLite-база
  procurement/           отдельная SQLite-база
  tender-calendar/       планы подготовки и назначения
  contract-experience/   отдельная SQLite-база
  staff/                 отдельная SQLite-база
  attachments/
  attachment-staging/    файлы только до успешного сохранения карточки
  backups/
  exports/
```

Перед миграциями базы создаётся страховочная копия. Полная резервная копия имеет расширение `.sbkbackup`; зашифрованная — `.sbkbackup.enc`. Восстановление сначала проверяет структуру и контрольные суммы, затем применяет данные транзакционно.

Для общей папки файловая система должна поддерживать эксклюзивные блокировки файлов и атомарное переименование. Права просмотра и редактирования назначаются средствами Windows/сервера файлов; отдельные пароли внутри приложения для этого не используются.
