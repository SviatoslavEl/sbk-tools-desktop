# Демонстрационные файлы СБК Инструменты

Все названия организаций, реквизиты, сотрудники, цены и сроки в этой папке вымышлены.

- `Демо_закупка_лабораторного_оборудования.docx` - три страницы с таблицами, кириллицей, колонтитулами и явными разрывами страниц. Используйте для проверки загрузки DOCX, предварительного просмотра и сохранения исходной геометрии страниц.
- `Демо_скан_коммерческого_предложения.pdf` - двухстраничный PDF, состоящий только из изображений. Используйте для демонстрации автономного OCR, фильтров и сборки итогового PDF.
- `Демо_скан_ценового_предложения.jpg` - отдельная страница скана для быстрой демонстрации обработки изображения.
- `Демо_календарь_тендеров.xlsx` - календарь закупок, сотрудники, квалификация, загрузка, формулы и диаграмма. Используйте для демонстрации импорта и аналитики тендерного модуля.

Файлы не требуют интернета и не содержат персональных либо конфиденциальных данных.
