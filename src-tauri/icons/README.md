# СБК Инструменты: иконка приложения

Исходник — `public/sbk-tools.svg`: документ и инструмент в цветах интерфейса
(индиго и бирюзовый). Он не зависит от шрифтов или внешних изображений.

После изменения исходника выполните из корня репозитория:

```sh
node scripts/generate_app_icons.mjs
```

Установленный в проекте Tauri CLI создаёт все размеры из SVG. Генератор обновляет
только существующие 16 файлов иконок для десктопа; мобильные ресурсы в репозиторий
не добавляются. ICO содержит в том числе 16, 32, 48 и 256 px, ICNS используется
macOS. Windows-приложение, установщик и удаление программы используют общий ICO.
Имена файлов, идентификаторы приложения и пути пользовательских данных остаются
прежними. Неактивный portable-launcher версии 2.8.3 не изменяется.
